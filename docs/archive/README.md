# Documentation archive

This directory contains completed implementation notes and historical planning material.

- `implemented/` — subsystem documentation that describes features already delivered in the consolidated baseline.
- `history/` — former phase plans, closing reviews, and plans that have already been implemented.

Archive documents are not active sources of truth. They may contain old branch names, phase states, file paths, or constraints that were correct at the time but are no longer current. Use root `docs/` files for present development decisions.
